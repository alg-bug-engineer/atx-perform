# 交通智能体平台架构图绘制 Prompt（v1）

> 生成日期：2026-08-21。与《架构图绘制prompt-v3.md》（双工程系统架构）相互独立，
> 本图面向交通智能体平台总体架构汇报。风格基准：Google Cloud / Microsoft Azure
> 官方架构图的扁平化规范。

请绘制一张「城市交通智能体平台」总体架构图，横向 16:9，白底扁平化风格，

【关键数据流箭头（带标注）】
1. 感知采集链（粗实线主链路）：设备层 → 数据层「车流量等感知数据汇聚」
2. 算力支撑链（虚线）：服务器层 → 智能体集群层「Qwen 35B / 2B 模型推理服务」
3. 数据读写链（双向实线）：数据层 ↔ 智能体集群层「取数分析 / 结论回写」
4. 技能调用链（双向实线）：多智能体集群 ↔ 专家技能包「调用 / 输出优化策略」
5. 技能固化闭环（虚线回环）：评价反馈与闭环进化智能体 → 专家技能包
6. 能力输出链（粗实线主链路）：智能体集群层 → 业务层 → 应用层
7. 闭环控制链（沿全图右缘一条竖向虚线回到最底层）：业务层 / 应用层 →
   信号机「优化信控方案下发执行」，与第 1 条链首尾相接，
   构成「感知 — 决策 — 控制」全闭环

  模块网格严格对齐，层间留白一致，禁止拟物、禁止滥用渐变、禁止 3D 效果
- 配色：低饱和专业色系，每层一个主色：设备层深灰蓝 / 服务器层深蓝 /
  数据层青色 / 智能体集群层靛蓝（视觉重心，饱和度略高）/ 业务层蓝绿 /
  应用层天蓝；同层内用同色系深浅区分；正文文字统一深灰
- 字体：无衬线（思源黑体 / HarmonyOS Sans / Segoe UI / Roboto），
  层标题加粗、模块名常规字重
- 图标：全套统一线性图标（Material Symbols / Fluent Icons 风格），
  设备层用简笔实物线稿
- 连线：直角折线；实线 = 数据流（灰蓝），虚线 = 控制指令与闭环回路
  （橙 / 绿点缀色），主链路加粗，箭头样式全局统一
- 画布：横向 16:9；标题「城市交通智能体平台总体架构」置于顶部左侧；
