§1

文档定位与确定性约束

把「开盲盒」变成「按剧本逐帧复现」

本 PRD 将动态智能体交互转化为完全可控、确定性强的汇报演示：每幕显示什么、文案怎么念、颜色怎么给、何时切换，均以本文档与 data/ 剧本 JSON 为唯一依据，工程实现不得自由发挥。

约束编号要求
C-1 数据确定所有数值绑定 data/ 剧本 JSON（路径见各幕节拍表），禁止运行时查库、实时拉数或二次推算改写展示值。
C-2 文案确定屏显文字与口播逐字稿以本文档为准；改文案须先更新本文档与附录速查，再改代码。
C-3 配色确定仅允许五类语义色（见图例与下表）；严禁随意用色。白底主题色值：中性 #0f172a / #64748b、红 #dc2626、琥珀 #b45309、绿 #059669、青 #0891b2。
C-4 时序确定画面切换按各幕节拍表执行（±0s）；有预合成语音的幕以 WAV 时长为拍，无语音的幕按字幕节拍表执行。
C-5 无随机性演示路径禁止随机数、实时请求、agent 自由生成文本；零 JS 静态文档亦须满足标签配对、双击可开。
C-6 分支与验收功能开发走时间戳分支（YYYYMMDD-HHMMSS-<task>），禁止自动合入 main；验收 = 逐帧比对本文档 + 附录速查全数命中。
