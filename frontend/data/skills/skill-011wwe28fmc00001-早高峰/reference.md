# 诊断依据与策略要点明细

## 用户原始诉求

> 早高峰那两小时，北口直行老往外溢；看看本口配时还能不能抠点绿；别这边加绿把拥堵甩下游去

## 策略原则

1. 下游阻塞未解除前，严禁增加目标路口北向南直行绿灯时长
2. 优先保障下游奥体西路与经十路路口消散能力，实施上游截流保护
3. 干线协调联控优于单点配时优化，防止拥堵在短距离路段间震荡转移

## 推荐做法

1. 目标相位（北向南直行）绿灯 −2s
2. 信号周期 ±0s
3. 核对奥体西路与解放东路路口至奥体西路与经十路路口走廊车队到达与相位差是否错峰
4. 晚高峰对北向南直行出口及奥体西路与经十路路口进口开展视频巡检，清除违停占道
5. 加强机非隔离与借道冲突劝导，保障绿灯有效放行
6. 下游保护约束下的保守放行

## 不建议做法

- 直接增加目标路口北向南直行绿灯时间
- 在未监测下游排队状态下盲目执行历史案例中的增绿策略
- 仅调整目标路口配时而不同步调整上游坤顺路路口信号
- 压缩目标路口周期导致下游清空时间不足

## 硬约束（红线）

- 下游奥体西路与经十路路口北向南饱和度≥1.8时，禁止任何增加目标路口北向南绿灯的动作
- 上游坤顺路截流后，其北向南排队长度不得超过路口停车线后50米，否则立即回滚原配时
- 所有配时调整必须在非高峰平峰过渡期（如9:00-9:30）试运行至少3个周期后方可进入高峰执行
- 目标路口北向南直行绿灯最低不得低于15秒，防止公交车无法一次性通过引发二次排队
- 各机动车相位不得低于对应最小绿，黄灯、全红与行人清空时长保持不变
- 单相位绿灯不得超过 60s（最大绿上限）
- 信号周期不得超过 180s（最大周期约束）

## 策略解释

当前下游奥体西路与经十路路口饱和度达2.19且处于阻塞状态，目标路口queue_ratio=1.41证实已发生回溢。历史案例Top1/Top3虽提及小步增绿，但其前提均为下游具备承接余量或已实施有效截流，本案下游完全阻塞且无实时感知设备支撑动态调节，直接套用增绿策略将导致拥堵向上游坤顺路及横向道路扩散。故必须反向操作：先削减目标路口及上游绿灯供给，同时最大化下游消散能力，待下游饱和度降至0.9以下后再评估是否恢复或微调目标路口配时。交通组织与管理措施旨在物理层面辅助信控截流效果，弥补数据缺失下的控制盲区。

## 预期效果与回滚

- 预期效果：抑制向下游继续送车，避免外溢扩散
- 回滚条件：下游排队比持续上升时回滚至原方案
