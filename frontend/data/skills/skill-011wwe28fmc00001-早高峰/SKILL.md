# 奥体西路与解放东路路口 治理技能

## 诊断结论

- 路口：奥体西路与解放东路路口
- 路口 ID：011wwe28fmc00001
- 时段：07:00–09:00
- 方向/转向：北向南 / 直行
- 问题类型：溢出
- 诊断范围：本口配时优化
- 治理目标：缓解北口直行溢出且不影响下游通行

## 治理策略要点

### 原则

- 下游阻塞未解除前，严禁增加目标路口北向南直行绿灯时长
- 优先保障下游奥体西路与经十路路口消散能力，实施上游截流保护
- 干线协调联控优于单点配时优化，防止拥堵在短距离路段间震荡转移

### 推荐做法

- 目标相位（北向南直行）绿灯 −2s
- 信号周期 ±0s
- 核对奥体西路与解放东路路口至奥体西路与经十路路口走廊车队到达与相位差是否错峰
- 晚高峰对北向南直行出口及奥体西路与经十路路口进口开展视频巡检，清除违停占道
- 加强机非隔离与借道冲突劝导，保障绿灯有效放行
- 下游保护约束下的保守放行

## 配时建议摘要

- 推荐方案：下游保护方案
- 周期：158s
- 西直、东直、东右、南行人、北行人：绿灯 54s
- 东左、西左、东右：绿灯 30s
- 北直、南直、东右、西行人、东行人：绿灯 35s
- 南左、北左、东右：绿灯 19s

## 约束与红线

### 用户约束

- 避免增加绿灯时间导致拥堵转移至下游路段

### 策略红线

- 下游奥体西路与经十路路口北向南饱和度≥1.8时，禁止任何增加目标路口北向南绿灯的动作
- 上游坤顺路截流后，其北向南排队长度不得超过路口停车线后50米，否则立即回滚原配时
- 所有配时调整必须在非高峰平峰过渡期（如9:00-9:30）试运行至少3个周期后方可进入高峰执行
- 目标路口北向南直行绿灯最低不得低于15秒，防止公交车无法一次性通过引发二次排队
- 各机动车相位不得低于对应最小绿，黄灯、全红与行人清空时长保持不变
- 单相位绿灯不得超过 60s（最大绿上限）
- 信号周期不得超过 180s（最大周期约束）

## 预期效果与回滚

- 预期效果：抑制向下游继续送车，避免外溢扩散
- 风险提示：目标进口排队缓解速度较慢，需配合上游控流
- 回滚条件：下游排队比持续上升时回滚至原方案
